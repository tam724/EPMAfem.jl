The boundary term arising from integration by parts 
$$\int n \cdot{} \Omega u_0 v_1 d \Omega d \Gamma$$
since $v_1 = v_1^{e, n} + v_1^{o, n}$ and the order factor $n\cdot{}\Omega u_0$ is odd, wrt. $n$, we have
$$= \int n \cdot{} \Omega u_0 v_1^{o, n} d \Omega d \Gamma$$
$$ = 2\int_{n\cdot{}\Omega<0} n \cdot{} \Omega u_0 v_1^{o, n} d \Omega d \Gamma$$
$$ = 2\int_{n\cdot{}\Omega<0} n \cdot{} \Omega (u - u_1) v_1^{o, n} d \Omega d \Gamma$$
$$ = -2\int_{n\cdot{}\Omega<0} n \cdot{} \Omega (u_1^{e, n} + u_1^{o, n}) v_1^{o, n} d \Omega d \Gamma + 2\int_{n\cdot{}\Omega<0} n \cdot{} \Omega g v_1^{o, n} d \Omega d \Gamma$$
$$ = -2\int_{n\cdot{}\Omega<0} n \cdot{} \Omega u_1^{e, n}  v_1^{o, n} d \Omega d \Gamma - 2\int_{n\cdot{}\Omega<0} n \cdot{} \Omega u_1^{o, n} v_1^{o, n} d \Omega d \Gamma + 2\int_{n\cdot{}\Omega<0} n \cdot{} \Omega g v_1^{o, n} d \Omega d \Gamma$$
$$ = -2\int_{n\cdot{}\Omega<0} n \cdot{} \Omega u_1^{e, n}  v_1^{o, n} d \Omega d \Gamma + \int |n \cdot{} \Omega| u_1^{o, n} v_1^{o, n} d \Omega d \Gamma + 2\int_{n\cdot{}\Omega<0} n \cdot{} \Omega g v_1^{o, n} d \Omega d \Gamma$$
